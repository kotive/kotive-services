# API endpoints to convert to apiv3

Inventory of **kotive-services** task definitions that call Kotive **`hub`**, **`bespoke`**, or legacy **`/api/`** routes on `https://webapp.kotive.com`. These are candidates for migration to **`/apiv3/`** (referred to in product docs as **api3**).

Generated by scanning all service `*.json` task files (excluding `drafts/`). Service-level `domain` from each folder’s `config.json` is applied when a task file omits `domain`.

## Summary

| Legacy surface | Task count |
|----------------|------------|
| `/api/` on `webapp.kotive.com` | 10 |
| `/bespoke/` (including bespoke proxy domains) | 6 |
| `/hub/` | 3 |
| **Total to convert** | **19** |

## Scope notes

- **Third-party APIs** (Twilio, GitHub, Mandrill, etc.) are out of scope; only Kotive-hosted `hub`, `bespoke`, and `/api/` routes are listed.
- **`drafts/`** was not scanned; no matches for `webapp.kotive.com` were found there at inventory time.
- In this repository, the v3 prefix is spelled **`/apiv3/`** in JSON task definitions.
